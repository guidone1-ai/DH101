# Audio Assets

This directory is set up to hold your custom audio tracks.

### Default Track:
- **Song:** *back of the club (instrumental)* by **kwn**
- **Recommended File Name:** `back-of-the-club-instrumental.mp3`

### How the Player Works:
1. **Local MP3:** If `assets/audio/back-of-the-club-instrumental.mp3` is present, the website will play your local MP3 directly.
2. **Streaming Fallback:** If no local file is found, the player smoothly streams the instrumental version via an integrated YouTube audio player (`0sTwFvKBLxc`).
3. **Vinyl Atmosphere:** You can also blend in or toggle warm vinyl needle crackles and low-frequency resonance.

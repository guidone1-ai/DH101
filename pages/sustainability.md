# Sustainability & Digital Ethics

> Environmental accountability and low-impact web architecture in critical making.

## The Physicality of Computing
While digital interfaces often appear weightless and clean, computational infrastructure has a substantial material footprint: energy-intensive data centers, water cooling systems, rare earth mineral extraction, and electronic waste.

## Sustainable Practices in this Portfolio
To minimize this site's environmental footprint:
1. **Lightweight Static Architecture:** The website uses vanilla HTML5, CSS3, and JavaScript without heavy npm dependency trees or heavy JavaScript frameworks that consume unnecessary server-side and client-side CPU cycles.
2. **Zero Bulky Audio Assets:** The ambient vinyl audio feature is generated in real-time on the client using the browser's native Web Audio API oscillators and noise algorithms, requiring zero extra megabytes of streaming audio bandwidth.
3. **Optimized Asset Delivery:** Avoids extraneous third-party trackers, redundant web fonts, and bloated render-blocking libraries.
4. **Mindful AI Generation:** Generative models are invoked with deliberate, concise prompting rather than high-frequency automated polling, reducing unnecessary compute burdens.
